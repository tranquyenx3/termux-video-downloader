# Termux Video Downloader Pro UI
Giao diện terminal nâng cấp, tối ưu cho màn hình điện thoại: màu sắc, khung tự co, menu rõ ràng, trạng thái và lịch sử.
Cài/ cập nhật:
```bash
cd ~/termux-video-downloader
git pull
bash install.sh
source ~/.bashrc
vdown
```
Hoặc chỉ thay giao diện:
```bash
cp vdown ~/bin/vdown
chmod +x ~/bin/vdown
vdown
```
Không cần root. Tool không xóa watermark; chỉ tải bản không watermark nếu nguồn cung cấp bản đó.
